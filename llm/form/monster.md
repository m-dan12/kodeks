# Анкета монстра

Первым полем всегда `kind = "monster"`.

## Основные поля

- `name` — название. `name_en` — английское название, если есть.
- `size` — tiny, small, medium, large, huge или gargantuan.
- `type` — aberration, beast, celestial, construct, dragon, elemental, fey, fiend, giant, humanoid, monstrosity, ooze, plant, undead. `subtype` — необязательно, например «гоблиноид».
- `alignment` — мировоззрение текстом.
- `cr` — опасность строкой: `"1/4"`, `"3"`, `"10"`. Выбери под роль монстра: бонус мастерства и опыт приложение возьмёт из неё. Ориентиры для остального — в таблице ниже.
- `ac` — класс доспеха числом, `ac_note` — пояснение («природный доспех»).
- `hp` — **средние хиты числом** из расчёта на CR. Приложение само подберёт кости хитов по размеру и Телосложению.
- `speed` — скорость в футах числом, либо блок `{ walk = 40, fly = 80, climb = 40, swim = 30, burrow = 20 }`.
- `abilities` — итоговые характеристики одной строкой в порядке: сила, ловкость, телосложение, интеллект, мудрость, харизма. Пример: `"20 12 17 3 12 7"`.
- `saves` — список характеристик с мастерством в спасбросках: `["dex", "con"]`. Числа не пиши.
- `skills` — список навыков с мастерством (ключи: perception, stealth, athletics и так далее). Числа не пиши.
- `resist`, `immune`, `vulnerable` — списки типов урона (acid, bludgeoning, cold, fire, force, lightning, necrotic, piercing, poison, psychic, radiant, slashing, thunder). `damage_notes` — текст для оговорок вроде «от немагических атак». `condition_immune` — список состояний (blinded, charmed, deafened, frightened, grappled, incapacitated, paralyzed, petrified, poisoned, prone, restrained, stunned, unconscious, exhaustion).
- `senses` — блок `{ darkvision = 60 }`; можно blindsight, tremorsense, truesight. Пассивную внимательность приложение считает само.
- `languages` — список языков (может быть пустым списком).
- `tactics` — как монстр ведёт себя в бою, 2–4 предложения. `description` — внешний вид, необязательно.

## Особенности

`traits` — повторяющиеся блоки: `name`, `text`; при ограничении `uses`. Для придуманных добавь `custom = true`.

## Действия

Повторяющиеся блоки `actions`, `bonus_actions`, `reactions`, `legendary`. Тип блока приложение определяет по полям.

**Атака** (есть `dice`):
- `name`, `ability` (str или dex: бонус попадания и урон считаются от неё), `dice` (кости урона без модификатора, `"2d8"`), `damage` (тип урона);
- `reach = 5` для рукопашной; для дальнобойной `range = "80/320"` (нормальная и дальняя дистанции);
- `extra = ["1d6 fire"]` — дополнительный урон другого типа;
- `add_mod = false`, если модификатор к урону не добавляется;
- `spell = true` для атаки заклинанием;
- `text` — дополнительный эффект при попадании («цель схвачена, Сл 14»).

**Мультиатака:** `kind = "multiattack"`, `text` (как в книге) и `plan` — список названий атак, у которых надо повторять через `x`: `["Укус", "Коготь x2"]`. Названия должны совпадать с названиями атак.

**Спасбросок цели** (есть `save`): `name`, `save` (характеристика спасброска цели), `dc` (характеристика монстра, от которой считается Сл: `"con"`; либо число, если Сл взята из книги), `dice` и `damage` (урон), `area` («конус 30 фт.»), `on_success = "half"` (или `"none"`, `"special"`), `text` (дополнительный эффект).

**Прочее** (особый эффект без числовой механики): `name` и `text`.

Общие поля для любого действия: `uses` — ограничение: `"recharge 5"` (перезарядка 5–6), `"3/day"`, `"1/long"`. В блоках `legendary` стоимость в `cost = 2` (по умолчанию 1). Количество легендарных действий в раунд: `legendary_per_round = 3`.

## Для всех

- `notes` — список заметок для мастера. `doubts` — список сомнений: баланс, формулировки, в чём не уверен.
- `book = "SRD 5.1"` у самого монстра пиши, только если это дословно официальный монстр. Иначе монстр считается придуманным.

Приложение сверит заявленный CR с расчётом по защите и нападению. Расхождение больше чем на одну ступень даст предупреждение. Сопротивления, иммунитеты и легендарные действия в расчёте не учитываются: для таких монстров подправь показатели сам и отметь это в `doubts`.
