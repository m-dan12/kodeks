# Кодекс

Офлайн-приложение для D&D 5e (редакция 2014): нейросеть придумывает существо, приложение проверяет, считает все числа по правилам и выдаёт карточку. Работает без интернета на телефоне (Android) и на Windows.

**Главное правило: LLM выбирает и придумывает, приложение считает.** В анкете нет модификаторов, бонуса мастерства, КД, максимума хитов, бонусов атак, Сл заклинаний и ячеек: всё это приложение считает само.

## Как это работает

1. В мастере создания выбираете, кого придумать (персонаж, НИП, монстр), и копируете один промт: правила и задание одним сообщением.
2. Вставляете промт в любую нейросеть и копируете её ответ: анкету в формате TOML.
3. Приложение разбирает анкету, показывает ошибки с подсветкой строк (их можно скопировать обратно в чат) и сохраняет карточку в библиотеку.
4. Карточку можно смотреть, править, раскладывать по полкам и экспортировать в PDF (печать A4 или длинный лист для экрана). Для персонажа есть файл для Long Story Short.

## Установка

Готовые сборки лежат в [релизах](https://github.com/m-dan12/kodeks/releases):

- `kodeks-*.apk`: Android (разрешите установку из неизвестных источников).
- `kodeks-*-windows.zip`: Windows, распаковать и запустить `Kodeks.exe`.

При запуске приложение смотрит новые релизы и предлагает обновиться.

## Разработка

```bash
npm install
npm run dev          # веб-версия
npm test             # тесты
npm run typecheck    # типы
npm run build:exe    # сборка для Windows в out/exe
```

APK собирается в WSL: `npm run build && npx cap sync android && bash scripts/build-apk-wsl.sh`.

Версия берётся из `package.json` и переносится в Android скриптом `scripts/sync-version.cjs` (запускается перед сборкой).

### Устройство

- `src/` — проверка анкет (Ajv, русские сообщения), правила и расчёты, PDF (`@react-pdf/renderer`), интерфейс (`src/web`).
- `schema/` — JSON-схемы персонажа, НИП и монстра; `llm/` — инструкции для нейросетей (собираются командой `npm run llm:kits`).
- `electron/` и `android/` — оболочки для Windows и Android (Capacitor).
- `examples/`, `tests/`, `docs/` — примеры, тесты и заметки.
